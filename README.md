# AI Project

Actividad formativa GitHub Copilot - sistema de recomendación con IA

## Mejora del código

Inicialmente, GitHub Copilot generó un sistema básico que identificaba películas en común entre usuarios. Luego se refinó la instrucción para que el sistema recomendara películas que un usuario con gustos similares ya había visto y que Alice aún no tenía en su lista. Después de ejecutar nuevamente el programa, se obtuvieron como recomendaciones “The Dark Knight” y “Batman Begins”.
