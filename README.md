# AI Project

Actividad formativa GitHub Copilot - sistema de recomendación con IA

## Desarrollo de la actividad

Se creó un sistema simple de recomendación de películas utilizando Python y GitHub Copilot.

Inicialmente, Copilot generó una propuesta básica a partir de una instrucción escrita en el archivo `recommendation_system.py`. Luego se revisó el resultado y se mejoró la instrucción para que el sistema recomendara películas de usuarios que compartieran al menos una película favorita con Alice.

## Mejora del código

La primera versión del programa entregaba resultados que no correspondían completamente a una recomendación basada en gustos similares. Por esta razón, se refinó la instrucción dada a GitHub Copilot para mejorar la lógica del sistema.

La nueva versión permitió identificar usuarios con al menos una película favorita en común con Alice y recomendar títulos que ella aún no tenía en su lista.

## Resultado final

Después de ejecutar nuevamente el programa, se obtuvieron las siguientes recomendaciones para Alice:

- The Dark Knight
- Batman Begins

Este resultado permitió comprobar que una instrucción más clara y específica puede mejorar la respuesta generada por GitHub Copilot y hacer que el código se acerque mejor al objetivo planteado.
